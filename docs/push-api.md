# Αποστολή αποθέματος στο Euronics — οδηγός για τον τεχνικό του ERP

Αφορά τα μέλη που επέλεξαν «Αποστολή από το σύστημά σας». Το ERP σας στέλνει περιοδικά το απόθεμα των καταστημάτων σας. Εμείς δεν συνδεόμαστε στο σύστημά σας.

## Στοιχεία

- **Διεύθυνση**: `POST https://b2b.dgsmart.gr/api/v1/stock`
- **Κλειδί**: το παίρνετε από την πύλη B2B (Σύνδεση → Κλειδί API). Εμφανίζεται **μία φορά**, γι' αυτό φυλάξτε το. Αν χαθεί, εκδίδετε νέο και ανακαλείτε το παλιό.
- **Headers**: `Authorization: Bearer eus_…` και `Content-Type: application/json`

## Σώμα

```json
{
  "mode": "full",
  "items": [
    { "sku": "123456", "location": "01", "qty": 4, "ean": "5201234567890", "mpn": "WAN28262GR", "brand": "BOSCH", "title": "Πλυντήριο ρούχων 8kg" },
    { "sku": "123457", "location": "02", "qty": 0, "ean": "5201234567891" }
  ]
}
```

| Πεδίο | Υποχρεωτικό | Περιγραφή |
|---|---|---|
| `mode` | ναι | `full` = όλο το απόθεμα (ό,τι λείπει θεωρείται 0) · `delta` = μόνο όσα άλλαξαν |
| `sku` | ναι | ο κωδικός είδους στο ERP σας |
| `location` | ναι | κωδικός αποθήκης/υποκαταστήματος στο ERP σας. Τον αντιστοιχίζετε μία φορά με τα καταστήματα στην πύλη |
| `qty` | ναι | διαθέσιμη ποσότητα (αριθμός) |
| `ean` | συνιστάται | barcode — με αυτό ταιριάζουμε τα προϊόντα πιο αξιόπιστα |
| `mpn`, `brand`, `title` | προαιρετικά | κωδικός κατασκευαστή, μάρκα, περιγραφή — βοηθούν όπου λείπει EAN |

## Όρια

- Έως **50.000 γραμμές** και **20 MB** ανά αίτημα. Για περισσότερα: ένα `full` την ημέρα και `delta` ενδιάμεσα.
- Έως **ένα αίτημα ανά 30″**. Αλλιώς απαντάμε `429` με `Retry-After` σε δευτερόλεπτα.
- Προτεινόμενη συχνότητα: `delta` κάθε 5–15′ και `full` μία φορά τη νύχτα.

## Απαντήσεις

| HTTP | Σημαίνει |
|---|---|
| `202` | ελήφθη: `{ "batchId", "accepted", "rejected": [{ "index", "reason" }], "rejectedTotal" }` |
| `422` | ελήφθη, αλλά καμία γραμμή δεν ήταν έγκυρη (δείτε `rejected`) |
| `400` | μη έγκυρο JSON ή σώμα |
| `401` | λάθος / ανακληθέν κλειδί |
| `403` | η σύνδεση δεν είναι ενεργή |
| `413` / `415` / `429` | πολύ μεγάλο / λάθος Content-Type / πολύ συχνά |

## Δοκιμή

```bash
curl -X POST https://b2b.dgsmart.gr/api/v1/stock \
  -H "Authorization: Bearer eus_ΤΟ_ΚΛΕΙΔΙ_ΣΑΣ" -H "Content-Type: application/json" \
  -d '{"mode":"delta","items":[{"sku":"TEST1","location":"01","qty":1}]}'
```

Μετά πατήστε «Έλεγχος σύνδεσης» στην πύλη. Θα δείτε πότε ήρθε το αίτημα, πόσες γραμμές έγιναν δεκτές και ποιες αποθήκες βρέθηκαν.
